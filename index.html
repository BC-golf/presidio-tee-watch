This app edits the settings in your GitHub project. It needs a one-time access key that only works on that project.

  1. Open GitHub → new access token.
  2. Name it "Tee Watch". Set expiration as long as allowed.
  3. Repository access: Only select repositories → presidio-tee-watch.
  4. Permissions → Repository: Actions = Read and write, Contents = Read and write.
  5. Tap Generate token, copy it, and paste it below.

The key is stored only on this phone.
